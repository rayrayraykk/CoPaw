# Workspace 目录代际验收

日期：2026-09-09；计划 §14.2.24.46。注册入口与恢复文件事务已接入，Cron/聊天等消费者的端到端归属仍未完成。

## 行为与边界

`.qwenpaw-workspace.json` 保存 Core 管理的类型化数据标识，重新注册要求规范路径索引和目录内标识同时匹配。目录在注册之前已被替换且没有原标识，或新自定义目录在创建失败后留下，都不能仅凭路径接回旧绑定。普通文件编辑和原目录换公开 Agent ID 保留绑定；复制分配新的标识。

注册表 v3 启动不补足丢失的标识。已有原生 v1/v2 只在升级时为已知目录建立一次基线；不追溯猜测升级前文件系统变更，也不导入 Python 数据。损坏、超限、非法身份和符号链接标识拒绝处理。标识文件不是安全凭据；同权限进程有能力复制/伪造它，不以此声称所有文件系统替换竞态已解决。活动运行入口的核对仍需随统一消费者接通。

恢复保留原整目录/受保护子项交换算法，将本机规划标识写入暂存内容，并与配置/目录交换一起回滚。归档不能提供标识，不改变未选中标识的原字节。初版试图用受保护标识强制逐子项交换，导致空目录与新目录回滚回归失败；已撤回该交换策略，原回滚和完整目录树断言继续保留。

原文件列表、下载、监视通知、检查点和 Workspace 备份不包含标识。原文件/上传路径拒绝改写该保留文件。Git 在仓库自身 info/exclude 中追加该文件的排除规则，保留用户原规则，不改全局配置；真实 Git 暂存全部与清理验证标识不会被带入暂存或删除。实际测试只在临时目录/仓库进行。
