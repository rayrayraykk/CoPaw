# 普通 Console 运行生命周期验收

日期：2026-09-09；计划 §14.2.24.50。延续聊天 Workspace 归属，不改原页面或对外协议。

## 实现范围

- HTTP 聊天在 Agent 生命周期锁内读取一次经过目录标识校验的注册快照，使用该快照的模型选择、项目、运行策略及聊天归属创建 Turn，并在释放锁前登记活跃运行。关闭/删除不能插入读取与运行登记之间。
- 每次普通运行保存入场时的审批身份（Agent、session、root session）；审批事件不在执行过程中重新寻找同名注册。持久聊天数据仍由 Workspace 标识授权，SSE 终态沿用原 `canceled` / `completed`。
- 关闭/删除发布注册状态后取消其 Cron 与普通 Console 运行，释放 Cron/Agent 状态锁后等待完成。成功响应是退出与待审批清理的界限；等待超时仍返回 503，不伪造成功。
- 运行消费独立于 SSE 接收者：连接断开立即中断等待模型的 Turn；取消可打断发送背压，持续消费 Core 终态再释放运行。取消时不等待已满的前端队列，队列有空间则保留原事件。HTTP 服务关闭也取消并跟踪这些任务。
- 默认与其他 Agent 的活跃 Turn、完整待审批结构保持；同名新目录注册不能读取旧聊天，原目录重新注册仍按既有规则接回，不因为取消功能改变归属规则。

## 未完成边界

此处是应用内普通运行的入场与取消界限，不是文件系统外部替换防护或跨进程崩溃事务。使用量/ACL、检查点目录代际与完整多 Agent 路由、其余 Python 功能、CLI/TUI 与全平台安装态仍待完成；非默认公开 Cron 门禁不在此处解除。历史浏览器输入/导航偶发故障与旧安装包 SIGKILL 的证据继续保留。
