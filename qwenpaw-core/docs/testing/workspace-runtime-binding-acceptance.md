# Workspace 运行入口绑定验收

日期：2026-09-09；计划 §14.2.24.47。

## 改动与边界

内部 `AgentContext` 在注册锁内一次解析公开 Agent ID、固定数据标识、基础目录和配置。Workspace/config/model/project 读取统一通过它，核对规范路径索引与目录标识；缺失或失配返回 409，不自动写标识、重绑注册或修改目录内容。损坏/超限标识保持错误。项目目录从同一配置快照读取，不要求项目包含 Core 标识，也不以项目替代基础 Workspace 身份。

管理列表和删除仍可处理失效注册；其他 Agent 不受影响。前端源码和公开成功响应不变。这是入口时的绑定一致性检查，不是持有文件系统目录的安全租约；仍未把 Cron/聊天/审批/范围备份持久化全部改成数据标识，也没有证明运行中每个工具操作都能抵御目录替换竞态。
