# Agent 组合发布：私有凭据恢复接口验收

日期：2026-09-15，macOS ARM64。证据目录：`dist/qa-publication-credentials-20260915-3NmJDo`。承接 [持久恢复协议](../architecture/agent-publication-journal.md) 与 [提交判定基础](agent-publication-decision-acceptance.md)。本轮完成恢复凭据接口和比较现值的逆操作，不是 App Server 强杀恢复或完整发布验收。

## 实现

`DesktopCredentialStore` 增加读取、预留、清理恢复账户以及执行凭据逆操作的方法，供 Rust 宿主适配器使用；没有增加 HTTP、协议或 SDK 远程方法。未实现恢复存储的适配器明确返回不可用，不假装记录不存在。

系统凭据适配器使用独立的 `agent-publication-<installation UUID>-<transaction UUID>` 账户，仍交由既有 keyring 依赖处理，不复用模型、环境变量、Agent 业务或备份签名账户。Agent ID 在记录内校验，同一安装/事务换 Agent ID 不能绕过已占用账户。安装身份需要外围持久保存；当前没有根据目录或 Agent ID 猜测身份。

私有记录含版本、完整绑定、原值和拟发布值，明确区分 Missing 与 Present 空字符串。UUID 非 nil、Agent ID 合法性在构造及反序列化时检查；未知字段、缺失字段、重复字段、无效状态和跨绑定记录拒绝。预留不覆盖已有记录，写入后读回验证；清理匹配预期记录，删除后读回验证，已缺失允许幂等清理。存储报错不自动删除已写入的恢复副本。

逆操作只读取本次 Agent 的既有邮件凭据键：现值等于原值时不写；等于拟发布值才恢复原值；独立修改则拒绝覆盖。写入已生效但报错、或回读失败时，下一次重新检查现值，不重复已完成的写入。逆操作不清理恢复账户，外围文件恢复和提交判定完成后才能清理。原有业务键只抽取为共用函数，格式和优先级没有改变。

记录正文只传入凭据存储接口，不写 SQLite、普通文件或日志。新类型的 Debug 固定脱敏；JSON 解析、底层读写和清理错误不携带原始错误链或凭据正文。

## 测试与检查

每项测试使用独立账户替身或宿主适配器替身，未构造系统 keyring Entry、修改全局凭据 provider 或访问真实凭据。重新构造 Entry/宿主包装器时共享的是测试存储，不是新进程或真实 OS 持久化证明。

新增 10 项账户测试覆盖 9 种原值/新值组合、不同安装/事务隔离、同事务更换 Agent 拒绝、非法身份、严格损坏记录、重复预留、预期值冲突、读失败、写前/写后失败、错误成功应答、写后回读失败、删除前/后失败、错误删除成功应答、幂等清理、默认不可用和脱敏。新增 5 项逆操作测试覆盖缺失/空/非空完整组合、独立现值保留、恢复记录缺失/读取失败不触碰业务账户、写入失败后新包装器重试、回读失败后不重复写入。

`credentials-targeted` 首批 11/11：10 个新增项加 1 个已有组合发布凭据测试；不把它当作后加 5 项已运行的证据。首轮 Clippy 指出测试帮助函数多余的按值传递，已改引用；后加测试模块首次编译发现 glob 导入导致断言宏歧义，改显式导入。失败日志保留，没有关闭 lint 或放宽超时。

最终 `workspace-final` **812 通过、0 失败、31 显式项忽略**，111.05 秒，退出 0；全部 15 项新增测试进入完整运行。`clippy-final` 全工作区/全目标、警告即错误通过；`fmt-check` 通过。

原页面专项顺序 **4/4**：Agents 三项（33.16 秒，普通 Chat/Cron 停止及配置 CRUD/重开），邮件抽屉一项（11.62 秒，Agent 隔离、变更、刷新及重开）。两条命令均退出 0；本轮未重跑其他 27 个显式项，不将此前整组结果冒充本轮全部重跑。

`verify.mjs` 核对最终普通组、15 项新增回归、4 项页面、严格检查终态及保留的编译/lint 失败记录，并链式校验上轮证据、2,906 条来源和九个旧制品哈希。`verification.json` 记录当前文件哈希、进展分类和未完成边界；verified 不是整个 goal 或安装包发布通过。

## 未完成边界

- 现有真实 Profile 发布、文件日志与启动入口尚未调用这些接口。稳定安装 UUID 的落盘及跨重启加载也未接入；不能据此宣布强杀恢复可用。
- 本轮验证的是账户算法和适配器契约，未验证真实 Keychain、Windows Credential Manager 或 Secret Service 的持久性、权限提示、容量和强杀行为。
- 凭据库的先读后写/删不是跨进程原子 CAS。宿主仍须持有发布锁，完整在途任务屏障与外部竞态未关闭。
- 原前端与浏览器脚本未改；没有重建 release Core 或九类制品，没有执行包内 Core、原生 Desktop 或 VS Code 激活。旧 `eaTvv4` 不包含这些后续修复，跨平台实机和既有焦点/SDK EOF 间歇问题继续开放。
