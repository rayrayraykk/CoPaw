日期：2026-09-15，macOS ARM64。证据目录：`dist/qa-publication-decision-20260914-w5Qte3`（目录在本地日期跨日之前创建）。方案与架构图见 [持久恢复协议](../architecture/agent-publication-journal.md)。仅完成协议前三项，不表示完整恢复功能或 goal 完成。

## 实现范围

Storage 新增安装级 `agent_publication` 表，只有单一槽位、事务 UUID 和 prepared/committed 状态；不保存配置正文、路径或凭据。预留只接受空表，损坏/非标准槽位也不能被新事务绕过。读取验证 UUID 规范形式、状态、槽位与单记录条件。

提交以 SQLite Immediate 事务同时更新判定和规范 Channels 配置键；任何一步 SQL 写入失败都回滚。`None` 不更改 Channels，已有值和原来不存在两种状态都保留。重复预留、陈旧 ID、错误状态和重复提交拒绝，不覆盖 Channels；完成回滚/清理之后，调用方只能清除对应 ID/状态。

逻辑备份不导出该表，另一数据库恢复业务数据后没有本地判定。本地有 prepared/committed（包括损坏记录）时，备份替换在删除任何业务表之前拒绝。没有待处理记录的既有备份流程保持原行为。

Core 提供显式读/预留/提交/清理方法，所有写入取得现有 operation guard，独占恢复期间返回 RestoreBusy；读取保持既有只读接口语义。Channels 常量共用，不增加协议、HTTP 或 SDK 方法。
