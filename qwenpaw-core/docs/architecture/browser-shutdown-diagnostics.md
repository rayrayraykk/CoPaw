# 原页面测试：浏览器退出时序诊断

延续原交互等价验收，针对完整回归中的 `Browser did not exit after close request`。已知页面断言先完成，未知浏览器为何未在现有 2 秒期限内退出。此阶段只补充证据，不将关闭慢解释为产品无问题，也不延长超时或强杀后判成功。

## 改动方案

只为新增的产品版本浏览器驱动接入可选时序观测，原 Console、Rust 产品代码和共享 `closeBrowser` 判定不改。显式提供独立 QA 输出目录时记录：调用前、匹配的协议响应、socket 关闭/错误、主进程 exit/stdio close、正常收尾或失败、SIGTERM/SIGKILL 清理及清理结束。观察器不发请求、不操作进程、不添加等待，只保存有界事件和时间/PID；不保存协议正文、URL、请求头或凭据。

诊断文件采用唯一目录，不覆盖旧日志。现有成功/失败仍由原页面断言与共享 2 秒关闭检查决定。写诊断失败不能掩盖原测试错误，外层验收单独拒绝缺失报告。
